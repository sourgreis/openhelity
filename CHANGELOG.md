## [0.1.0] — 2026-10-23

First public version, for the ZUOYA HE30.

### Added

- Keymap editing across 3 profiles × 4 layers.
- Per-key actuation point, Rapid Trigger and continuous Rapid Trigger.
- Live key press depth and a key tester.
- Key backlight, per-key colours and the indicator LED.
- Advanced keys: DKS, Toggle, Mod-Tap and SOCD.
- Macros recorded from the keyboard or entered by hand.
- Copying between layers and profiles, local backups, JSON import and export.
- English and Russian interface.
- Offline use as an installable web app.
- Licence notices of the Rust crates compiled into the page, published as
  `pkg/THIRD-PARTY-NOTICES.txt`.
